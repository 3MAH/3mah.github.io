# 3mah.github.io

Source of <https://3mah.github.io>, built with [Zensical](https://zensical.org).

```bash
python -m venv .venv && source .venv/bin/activate
pip install "zensical>=0.1.3,<0.2"
zensical serve        # http://localhost:8000, live reload
zensical build        # static site in site/
```

- Pages: `docs/*.md` (URLs follow the file path: `docs/team.md` → `/team/`)
- Images and videos: `docs/assets/images/` (regenerated by `scripts/render_*.py`)
- Navigation, theme, extensions: `zensical.toml`
- Styles: `docs/assets/stylesheets/extra.css`; SEO meta / JSON-LD: `overrides/main.html`
- Deployment: `.github/workflows/docs.yml` (GitHub Pages → Source: *GitHub Actions*)

## Link with the library documentation

The Sphinx docs of simcoon, fedoo and microgen are the reference for installation,
tutorials, examples and API; this site points to them.

- `scripts/build_examples.py` reads the sphinx-gallery index of each library and generates
  `docs/examples.md` (unified gallery) and `snippets/examples_<lib>.md` (featured examples on
  the library pages). Featured examples are chosen in the `LIBRARIES` table of the script.
- `scripts/check_doc_links.py` fails the build if a link to the Sphinx docs returns an error.
- Old guide URLs (`/docs/...`) redirect to the matching Sphinx pages (`zensical.toml`, `redirects`).
- The site is rebuilt on push, every Monday, and when a library workflow sends a
  `repository_dispatch` event of type `docs-updated` to this repository.

Local workflow:

```bash
python scripts/build_examples.py && zensical build && python scripts/check_doc_links.py
```
